# Hayat — Web Platform

The web-based companion to the Hayat hospital app, built for a Web Design course (IS311): a
patient/doctor/admin portal with login and profiles, a MySQL-backed appointment system (see
`hayat_database.sql`), and a Node.js/Express API layer (`server.js`) added in a later phase.

`legacy/` keeps the earlier phase submissions (Phase 2 static HTML, Phase 4 Node.js backend) for
reference. `docs/` has the Phase 1 report.

## Tech
Node.js, Express, MySQL, HTML/CSS
